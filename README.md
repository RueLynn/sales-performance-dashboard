# Sales-performance-dashboard
An end-to-end retail sales analytics project using Excel, SQL and Power BI to evaluate revenue, profitability, product performance and regional trends.

**Tools:** Excel | SQL | Power BI | Power Query | DAX

**Project status:** In progress

## 1. Project Overview

This project focuses on analysing retail sales performance using the Sample Superstore dataset. The objective is to develop an interactive sales performance dashboard that provides insights into revenue, sales volume, profitability, product performance and regional trends.

The project demonstrates the application of data cleaning, exploratory data analysis, SQL querying, data modelling and business intelligence visualisation.

## 2. Business Problem

Businesses need reliable sales information to understand which products, categories and regions contribute most to revenue and profitability.

This project aims to answer the following business questions:

- Which product categories generate the highest revenue?
- Which products and sub-categories are underperforming?
- Which regions generate the highest sales and profit?
- How does sales performance change over time?
- How do discounts relate to profitability?
- What is the average order value?

## 3. Dataset

**Dataset:** Sample Superstore

**Source:** [Public dataset](https://csvbase.com/mdfarragher/Superstore/details)

**Coverage:** 2014–2017

The dataset contains retail transaction information, including order dates, products, customers, regions, sales, quantities, discounts and profit.
